## 🌟 ویژگی‌های برجسته
- **پشتیبانی کامل از پروتکل‌ها**: VLESS, VMess, Trojan, Shadowsocks, WireGuard, Hysteria2, TUIC v5, MTProto
- **رابط کاربری مدرن و واکنش‌گرا**: طراحی تاریک نئونی و اختصاصی بر پایه React 19 و Ant Design 6
- **سیستم چند ادمینی پیشرفته (RBAC)**: تعریف ادمین با سطوح دسترسی مختلف
- **پایگاه داده مستقل**: پشتیبانی از SQLite و PostgreSQL
- **پایش و مانیتورینگ دقیق**: گزارش لحظه‌ای مصرف منابع CPU، RAM و ترافیک کاربران

---

## 🛠️ نحوه نصب سریع

جهت نصب پنل روی سرور لینوکس (Ubuntu/Debian) دستور زیر را در ترمینال وارد کنید:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/ksgamer31/galexy-x-panel/main/install.sh)
```
